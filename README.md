# Library Management System (Java CRUD)

## Description

This is a simple Java-based console application that performs CRUD (Create, Read, Update, Delete) operations for managing books in a library.
The project uses ArrayList to store data and provides a menu-driven interface for user interaction.

## Features

* Add new books
* View all books
* Update book details
* Delete books
* Search book by ID
* Issue book
* Return book

## Technologies Used

* Java
* OOP (Object-Oriented Programming)
* ArrayList
* Scanner (for user input)

## Project Structure

* LibraryApp.java → Main application with menu
* Book class → Model class representing book data

## How to Run

1. Clone the repository:
   git clone https://github.com/ChanduMuthyala3116/LibraryAppCurd.git

2. Navigate to the project folder:
   cd LibraryAppCurd

3. Compile the program:
   javac LibraryApp.java

4. Run the program:
   java LibraryApp
